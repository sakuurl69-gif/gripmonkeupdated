ExtraGrip - Gorilla Tag mod (BepInEx 5)

1. Install BepInEx 5 (x64) into your Gorilla Tag folder and run the game once.
2. Double-click build.bat (uses the C# compiler already built into Windows).
3. Launch the game. Hold grip while touching a surface to hold on.

Config: BepInEx\config\com.extragrip.gtag.cfg
  SlideControl (1 = no sliding), GripStrength (0-1), RequireGripButton (true/false)

Use only in private/modded lobbies.
